MasterOfPuppets API Documentation

This API allows for local remote control over the MasterOfPuppets plugin.

Authentication

All endpoints (except static assets and documentation) require an authentication token if one is configured in the plugin settings.

You can authenticate by providing the token in the Authorization header:

Authorization: Bearer <token>

For WebSocket connections (where custom headers are not supported natively by standard browser APIs), you can provide the token as a query parameter:

ws://127.0.0.1:port/ws?token=<token>

REST API Endpoints

GET/api/v1/status

Returns the current state of the game client and plugin.

{
  "characterName": "Player Name",
  "isLoggedIn": true,
  "macroRunning": false,
  "connectedClients": 1,
  "serverVersion": "1.0"
}
GET/api/v1/macros

Returns a list of all macros configured in the plugin.

{
  "macros": [
    {
      "index": 0,
      "name": "My Macro",
      "tags": ["combat", "auto"]
    }
  ]
}
POST/api/v1/command

Executes a plugin command locally and broadcasts it to connected WebSocket clients.

Body:
{
  "cmd": "/mop run MyMacro"
}
POST/api/v1/broadcast

Broadcasts a macro action to all connected IPC clients.

Body:
{
  "cmd": "/clap"
}
POST/api/v1/broadcast/char

Broadcasts a macro action exclusively to a specific character via IPC.

Body:
{
  "character": "Player Name@World",
  "cmd": "/mop layout my_layout"
}
POST/api/v1/broadcast/group

Broadcasts a macro action exclusively to a specific group via IPC.

Body:
{
  "group": "Dancers",
  "cmd": "/mop layout my_layout"
}
POST/api/v1/macro/run

Runs a specific macro by name or 1-based index.

Body:
{
  "macro": "My Macro",
  "vars": "-var=$x=1;$y=2" // optional
}
POST/api/v1/chat

Sends a raw text message directly to the local game chat box.

Body:
{
  "message": "/p Hello Party!"
}

WebSocket API

WS/ws

Connects to the real-time event stream and command channel.

Incoming Messages (Client to Server)

{
  "type": "command" | "ping",
  "payload": "/mop stop" // Required for "command" type
}

Outgoing Events (Server to Client)

The server emits JSON objects containing the following format:

{
  "type": "event" | "pluginCommand",
  "name": "<eventName>", // Only for "event" type
  "data": { ... } // Payload data based on event
}

Possible Event Names:

  • macroStarted: Emitted when a macro starts playing.
  • macroStopped: Emitted when a macro stops.
  • commandResult: Result of a dispatched command (contains ok: boolean and error?: string).
  • broadcastReceived: Emitted when an IPC broadcast is received.
  • pong: Response to a client ping.
  • pluginCommand: Dispatched globally via REST or directly through WebSocket for synchronisation.
